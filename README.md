# Gravity Manipulation Puzzle Game

A third-person gravity-based puzzle platformer developed in Unity.

The player must manipulate gravity to navigate through levels and collect all cubes before the timer runs out.

---

## Features

- Third-person character controller
- Gravity manipulation system
- Hologram gravity preview
- 4 playable levels
- Cube collection objective
- Timer-based gameplay
- Game over and win conditions
- Character animations
- Dynamic gravity camera system

---

## Controls

| Action | Key |
|---|---|
| Move | W A S D |
| Jump | Space |
| Preview Gravity | Arrow Keys |
| Apply Gravity | Enter |
| Camera Look | Mouse |

---

## Gameplay Objective

- Collect all cubes before the timer ends
- Use gravity manipulation to navigate the environment
- Avoid obstacles and falling endlessly

---

## Gravity Mechanic

Arrow keys are used to preview gravity directions using a hologram system.

Press Enter to apply the selected gravity direction.

The player and camera rotate dynamically according to the active gravity orientation.

---

## Game Over Conditions

- Timer reaches 0
- Player falls endlessly
- Player collides with obstacles

---

## Win Condition

The game is completed after collecting all cubes in the level.
